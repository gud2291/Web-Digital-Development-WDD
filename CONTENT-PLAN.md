# CONTENT-PLAN.md — Blog / Article Roadmap (SEO + AEO)

Prioritized article ideas for the Web Digital Development blog, built to win Delhi +
service-keyword search **and** to be quoted by answer engines (Google AI Overviews,
ChatGPT, Perplexity, "People Also Ask", voice). Owner-driven via the admin panel;
each new post must ship with: a real `author` (Person), `datePublished` +
`dateModified`, 2–4 internal links, and Article schema (see plan §D4 / F3).

## How to use this list
- **Priority** = expected impact ÷ effort. Do P1 first.
- **Primary keyword** = the head term to put in the `<h1>`, URL slug and `seoTitle`.
- **AEO questions** = use these *verbatim* as `<h2>`/`<h3>` subheadings with a 40–60
  word direct answer immediately under each (feeds FAQ schema + featured snippets).
- **Internal links** = link these in-body with descriptive anchor text.
- Keep one brand suffix; titles ≤ 60 chars (the site appends `| Web Digital Development`).

## Publishing cadence (suggested)
- 2 posts/month, P1 first. Re-date evergreen posts (`dateModified`) every 6 months.
- Each post: 800–1,500 words, one `<h1>`, question-style `<h2>`s, a real author byline,
  and an FAQ block with matching `FAQPage` schema (the biggest AEO lever — see plan §C2).
- Interlink new posts with the relevant **service** page and at least one older post so
  link equity and topical clusters build over time.
